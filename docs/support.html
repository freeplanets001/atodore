「あとどれ？」に関するお問い合わせ、障害報告、削除依頼などは以下をご確認ください。

お問い合わせ先

不具合報告、改善要望、削除依頼などはGitHub Issuesからご連絡ください。

GitHub Issues

よくある質問

バーコードで商品名が出ないことがあります

外部データベースに商品が登録されていない場合、商品名候補を取得できません。その場合は商品名を手入力してください。

通知が届きません

iOSの通知許可、アプリ内の通知設定、商品別通知設定を確認してください。

データはどこに保存されますか

商品情報は端末内に保存されます。バックアップ機能を利用すると、ユーザー操作によりデータを書き出せます。
